# Chapter 1: Detection as a Classification Problem

> **Status**: scaffolded (M0 Day 14 deliverable per Round 22 priority order;
> prose fills at per-milestone close).

## Thesis

A detector is a binary classifier over the input space; design constraints
derive from the geometry of attacks. (Per `portfolio-chapter-outlines.md`
companion doc §Ch1.)

## R — Representation

What is a prompt-injection threat? Direct-vs-indirect framing; input/output
invariants (token sequences, context windows); prevalence across domains.

## O — Operation

How we formalize detection: threat taxonomy → binary-classification framing →
single-class metrics (val-fixed TPR per submission ADR-027 upstream-enforced) →
AUPRC/AUROC on multi-class slices.

## E — Evolution

From "jailbreaks" (2022) → "prompt injection" (OWASP 2023) → "indirect
attacks" (2024-25). Convergence on multi-vector threat models; divergence
on detection framing.
