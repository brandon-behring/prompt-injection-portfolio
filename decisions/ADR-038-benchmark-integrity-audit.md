# ADR-038: Benchmark integrity audit

## Status

Accepted (Round 7 Tier A Q1'''''' — zero-cost methodology guardrail).

## Context

Per the compass artifact survey + Goodhart-law analysis in submission's
ADR-064 §C1, evaluating a detector on a benchmark dataset that overlaps
with the detector's training data inflates measured AUC. The submission
predecessor's V4 finding documented ~8.4pp aggregate AUC inflation random
vs source-disjoint LODO splits.

Portfolio's eval slates include benchmark suites with known prior training
distributions:
- **PINT** (Lakera): may have been trained on by ProtectAI v1/v2.
- **PromptShield**: training data not fully disclosed.
- **NotInject**: an over-defense probe with specific provenance.
- **HackAPrompt**: large public corpus; could appear in pretraining mixes.

Portfolio MUST confirm it doesn't repeat the integrity-failure mode.

## Decision

At M0 (sub-deliverable per plan §9), audit each portfolio training-corpus
input + each eval slate for overlap. Specifically:

1. Lane 2's MR-3 synthetic corpus (~10k indirect-injection positives +
   ~10k benign carriers) is **synthetic** + freshly generated by Claude
   Sonnet 4.6 per ADR-041 (ETHICS content lock). No overlap with PINT /
   PromptShield / NotInject / HackAPrompt by construction.
2. The submission's training pool (used to train the frozen-probe
   baseline) excludes PINT + PromptShield + NotInject + HackAPrompt per
   submission ADR-016 LODO + cross-source disjoint splits.
3. Reference scorers (ProtectAI v1/v2, Meta PG2 86M) carry their own
   training-data provenance; portfolio does NOT use them in training, so
   their training-overlap with portfolio's evals is a downstream concern,
   not portfolio's.
4. Test-contract `leakage_scan_present` (Day 3b) enforces a leakage scan
   reference in lane protocols.

## Consequences

- Zero additional cost ($0 — audit is a paper exercise + scan script).
- Documents the Goodhart-law discipline portfolio inherits from
  submission + extends with Round 7 Tier A formality.
- ETHICS.md §3 (Responsible use) cites this ADR to discourage
  detector-leaderboards that compare detectors at inconsistent operating
  points / training mixes.
- If Tier C PromptShield Llama-3.1-8B unlocks: confirm PromptShield's
  training data publicly + adjust report if overlap exists.
